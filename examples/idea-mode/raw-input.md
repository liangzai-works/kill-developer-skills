# Idea-Mode 示例：医院索引巡检系统

> 这是一个 Idea 模式的输入样例。  
> 仅作为 **`software-factory` Smoke Test** 用，不是真实需求文档。

## 用户原文（一句话）

```
开发一个医院索引异常分析系统。日常巡检医院索引上报情况，
发现异常后能定位原因并给值班同事发通知。
```

## 应有的工作流反应

1. Phase 1.detect_mode 命中 Idea 模式。
2. Code Reviewer Agent 应主动补全：
   - 角色：运维值班 / 医院接口工程师 / 系统管理员
   - 范围：MVP 只做"巡检 + 报告"；告警 / 自动修复 留 V2
   - 非功能：单页加载 < 2s；并发 ≥ 50 医院
   - 数据字典：`医院`、`指标`、`上报日志`、`异常事件`
3. 应在 `requirement-analysis.md` 末节列出"假设清单"等待用户确认。
4. 然后按 `workflow.yaml` 串行跑完 8 Stage。
