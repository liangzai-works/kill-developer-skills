# <项目名>工作空间/

> software-factory v0.2.0 落地目录.
> 所有过程产物集中在一个目录, 阶段序号 NN 前缀标识.

## 1. 模板结构

```
<项目名>工作空间>/
├── 01_<项目名>_需求规格说明书.md
├── 详细设计模板.docx                (可选, 作为详细设计样式基线)
├── 02_<项目名>_详细设计文档.docx     (Stage 4 必出)
├── 03_<项目名>_架构设计.md
├── 04_<项目名>_数据库设计.md         (有 DB 时)
├── 源代码/
│   ├── <项目名>-server/             (后端)
│   └── <项目名>-web/                (前端)
├── 05_<项目名>_测试报告.md
├── 06_<项目名>_验收报告.md           (前端型必有)
├── 07_<项目名>_交付报告.md
└── screenshots/
    └── <NN>-<含义>.png
```

## 2. 命名约定 (v0.2.0 强约束)

- `NN` 两位数字前缀, 从 01 起, 表示阶段产出顺序
- `<项目名>` 全大写或驼峰, 与 workspace 目录名拼写一致
- 文档名中文, 单空格或下划线分隔
- 扩展名用文档本应格式

## 3. 详细设计模板 .docx

- 若工作空间存在 `详细设计模板.docx`, 详细设计文档以其为样式基线
- 模板文件本身不参与 .git (用户私有资产)
- 没有模板时自动用 docx skill 的默认模板
