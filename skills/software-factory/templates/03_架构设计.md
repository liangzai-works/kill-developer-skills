## ⚠️ 反例 (禁止)

下面这些是**禁止**在架构图和模块划分里出现的 SpringBoot 技术分层命名:

| 禁用 (技术分层) | 应该改为 (业务模块) |
|------------------|----------------------|
| 接入层 / 表现层 / 路由层 / API 网关层 | 用业务角色名 (例: 前台 / 后台 / 用户端 / 管理端) |
| 应用层 / 服务层 / 领域层 | 业务模块名 (例: 节点管理 / 用户管理 / 工单管理) |
| 持久层 / 数据访问层 / Repository 层 | 仅在"数据访问"模块下注明, 不作为顶层模块 |
| 基础设施层 | 仅在备注中说明 (Docker / 监控 / DB), 不作为架构图主层 |
